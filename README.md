# La Ronda

El contador oficial de lo que bebe la cuadrilla: bebidas, fichajes en bares y discotecas, estadísticas, ranking, Pruebas del Delito y El Burdel.

- Web/app: https://drak234.github.io/LaRonda/
- Datos: Firebase Firestore (`config.js`). Reglas de la base de datos en `firestore.rules`.
- Se instala en el móvil desde el navegador: "Añadir a pantalla de inicio" (iPhone) o "Instalar app" (Android).
